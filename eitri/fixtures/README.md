# Eitri fixtures

Parser and CAM test corpora. All files here are **hand-authored** for Eitri — no copyrighted vendor sample files
are included. `kicad-cli` was not available on the build host, so the Gerber/Excellon fixtures were written by hand
in faithful KiCad-style RS-274X / Excellon rather than generated by plotting the repo's `hardware/` board. Each is
small and targets a specific spec corner so a parser regression points straight at the construct that broke.

## `gerber/` — RS-274X (see `docs/eitri-porting-plan.md` §4)

| File | Provenance | Exercises |
|------|-----------|-----------|
| `kicad_two_pads.gbr` | Hand-authored, KiCad `F.Cu` structure (`%TF` attributes, `FSLAX46Y46`, `MOMM`, `LPD`) | A realistic copper layer: two 2 mm `C` pads joined by a 0.25 mm trace → one connected copper polygon. The "real Gerber → copper MultiPolygon" bounds/area check. |
| `coords_leading.gbr` | Hand-authored | Coordinate decode with **leading-zero omission** (`FSLAX24Y24`), a pad at (5.0, 5.0) via `X50000`. |
| `coords_trailing.gbr` | Hand-authored | Same physical pad via **trailing-zero omission** (`FSTAX24Y24`, `X05`) — proves both omission modes decode identically. |
| `macro_thermal.gbr` | Hand-authored | An aperture **macro** (`AM` thermal primitive) defined and flashed — the macro interpreter + a macro-aperture flash. |
| `region_with_clear.gbr` | Hand-authored | A `G36/G37` **region** and an `LP` **clear** region cutting the dark one: copper area 100 − 16 = 84. |

## `excellon/` — drill files (see §5)

| File | Provenance | Exercises |
|------|-----------|-----------|
| `metric_leading.drl` | Hand-authored, KiCad drill structure | Declared **metric**, `TZ` (leading-zero suppression), `3.3`; a two-tool table and point drills. |
| `inch_trailing.drl` | Hand-authored | Declared **inch**, `LZ` (trailing-zero suppression), `2.4` — the inverted `LZ`/`TZ` keyword trap. |
| `slot_g85.drl` | Hand-authored | A `G85` **slot** (segment, not a point) buffered by the tool radius. |
| `undeclared_decimal.drl` | Hand-authored | **No** unit/format declaration; explicit-decimal coordinates parsed via inference fallback. |

Later phases will add `gcode/` golden files for the postprocessors (§8, §12).
